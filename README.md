# oc-git-clone
Клонирование репозитория Git в проект OpenComputers

# Использование

Выполнение скрипта в качестве команды оболочки с указанными аргументами:

1. `username` - ваше имя пользователя GitHub
2. `repository name` - имя репозитория для клонирования
3. `auth token` - персональный токен доступа (см. документацию [здесь](https://docs.github.com/ru/enterprise-cloud@latest/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens))

```shell
gitclone <username> <repository name> <auth token>
```
